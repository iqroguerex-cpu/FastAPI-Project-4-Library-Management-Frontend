# 📚 Library Management Dashboard (Streamlit Frontend)

[![Live Dashboard](https://img.shields.io/badge/Live-Dashboard-success?style=for-the-badge&logo=streamlit)](https://librarymanagementbychinmay.streamlit.app/)
[![Streamlit](https://img.shields.io/badge/Streamlit-Framework-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)](https://streamlit.io)
[![Python](https://img.shields.io/badge/Python-3.9+-blue?style=for-the-badge&logo=python&logoColor=white)](https://python.org)

An interactive **Library Management Dashboard** built using **Streamlit**.

This dashboard communicates with a **FastAPI backend** to manage books, users, and borrowing operations.

# ✨ Features

### 📊 Dashboard
* Library statistics
* Books analytics charts
* Borrowed vs available chart

### 📚 Book Management
* View books
* Search books
* Delete books

### 👥 User Management
* View users
* Search users
* Delete users

### 📖 Borrowing System
* Borrow books
* Return books

### ➕ Data Management
* Add books
* Add users

# ⚙️ Running Locally

Clone the repository

git clone https://github.com/iqroguerex-cpu/library-management-frontend

Navigate to project

cd library-management-frontend

Install dependencies

pip install -r requirements.txt

Run dashboard

streamlit run app.py
